# Roadmap

Vertical slices. Each phase ends with a usable, tested increment. **Current phase: 7** (Phases 0-6 done by 2026-10-14). Now 7.18 the media library, the storage view and purging from the trash (ADR-041, plan M0-M6); before it 7.17 the board of notes (ADR-040). Next: 7.4 importers (waiting on open question 13) or 7.7 backup encryption.
