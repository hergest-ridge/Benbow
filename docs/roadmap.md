# Roadmap

Vertical slices. Each phase ends with a usable, tested increment. **Current phase: 7** (Phases 0-6 done by 2026-10-14). Now 7.19 where the server keeps things, moving them, and the app from its own server (ADR-042, plan P1-P6, U1-U4, I1-I2); before it 7.18 the media library, the storage view and purging from the trash (ADR-041, plan M0-M6). 7.7 an encrypted copy outside the house (ADR-043, plan E0-E6) done 2026-10-22, not packaged yet; before it 7.19 (done). Then the owner's and a friend's small round (2026-10-25, ADR-045: picture links as attachments under their links with a loader, GIFs moving, ticked boxes in place, the editor's bar in two levels with hints, the trash by days with «Выбрать все», archive from an open note) built; servers 0.15.0 and 0.15.1 built. Now 7.20 the look of a note (ADR-047, plan L0-L9): L0 the spike done, L1 built (print backgrounds still to do). Now 7.21 trackers (ADR-050, plan B0-B8): B0 the docs and the spike built, the owner's feel applied; B1 the core, B2 the server and B3 the client built. Then 7.4 importers (waiting on open question 13).
